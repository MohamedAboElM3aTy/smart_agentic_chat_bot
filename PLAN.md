# Smart Agentic Chat Bot — Architecture Plan

## Overview

A Flutter e-commerce demo app for the GDG Cairo "Build with AI" workshop. The headline feature is an agentic chatbot powered by Firebase AI (Gemini) that understands natural language queries ("show me products under 50 EGP"), calls Firestore via function calling, and returns results as interactive product cards.

## Firestore Schema

```
users/{uid}
  uid: string
  username: string
  email: string
  createdAt: timestamp

products/{productId}
  name: string
  description: string
  price: number          # in EGP
  category: string       # Electronics | Clothing | Food | Books | Sports
  imageUrl: string
  stock: int

cart/{uid}/items/{productId}
  productId: string
  name: string
  price: number
  imageUrl: string
  quantity: int
```

## AI Chatbot Architecture

```
User message
    ↓
AiChatService.sendMessage(text)
    ↓
Gemini 2.0 Flash (firebase_ai)
    ↓  [if function call returned]
searchProducts(maxPrice?, minPrice?, category?, searchTerm?)
    ↓
FirestoreService.searchProducts(...)
    ↓
Products returned to Gemini as FunctionResponse
    ↓
Gemini generates final text + ChatMessage(text, products)
    ↓
ChatScreen renders text bubble + product cards (add-to-cart enabled)
```

### Function Declaration
```dart
FunctionDeclaration('searchProducts', 'Search store products', Schema.object(
  properties: {
    'maxPrice':   Schema.number(nullable: true),
    'minPrice':   Schema.number(nullable: true),
    'category':   Schema.string(nullable: true),
    'searchTerm': Schema.string(nullable: true),
  },
))
```

## Liquid Glass Navbar Design

Custom implementation using:
- `BackdropFilter` + `ImageFilter.blur(sigmaX: 20, sigmaY: 20)` for the glass effect
- Animated position `Tween<double>` following selected tab (spring-like)
- 5 items: Home | Categories | **Chat** (center, glowing) | Cart | Profile
- Cart tab shows a `Badge` with item count (from `cartController`)

## Workshop Demo Flow

1. Open app → Splash → auto-navigate to Login
2. Sign up with username + email + password
3. Home page shows product grid with Skeletonizer loading
4. Browse by category chips
5. Tap product → Product Detail → Add to Cart
6. Cart → Checkout (dummy confirmation)
7. **Main demo:** Chat tab → type "show me products under 50 EGP"
   → Gemini calls `searchProducts(maxPrice: 50)`
   → Products listed as cards in chat
   → User taps "Add to Cart" directly from chat
8. Profile → Seed Data button (for live demo reset)
